# still-sane-exile--repository
The repository for a Path of exile 2 Campaign guide.

topic: The website should be a guide to clear the Campaign of the Video game Path of Exile 2, since the Campaign can be quiet confusing.

audience: I plan to have a very beginner friendly guide but the main focus should be to increase efficency for more experienced players.

examples of content: since there are 6 acts in the campaign with each act having many different levels which have different permanent buffs, i plan to have a part, that shows which permanent buff is in which map. Also i would like to have level thresholds for each part of the campaign and maybe also some way of showing which items to look out for.
